1المتطلباتRequirements

  • جهاز يعمل بنظام Windows 10 أو Windows 11 بنسخة 64-بت.
  • صلاحية مسؤول (Administrator) على الجهاز مرة واحدة أثناء التثبيت.
  • مساحة فارغة 300 ميجابايت تقريباً.
  • اتصال بالإنترنت: البيع وفتح الوردية وإغلاقها تحتاج اتصالاً بالخادم.
  • رقم جوال وكلمة مرور لحساب وريد له صلاحية الدايت، ونقطة بيع معرّفة للشركة على الخادم.
  • لا حاجة لتثبيت .NET أو أي برنامج آخر: كل ما يلزم موجود داخل المثبّت.
  • A PC running Windows 10 or Windows 11, 64-bit.
  • Administrator rights on the PC, once, during installation.
  • About 300 MB of free disk space.
  • An internet connection: selling, opening and closing a shift need the server.
  • A Wrid account (mobile number and password) with Diet access, and a POS set up for the company on the server.
  • No need to install .NET or anything else: the installer contains everything.

2الحصول على ملف التثبيتGet the installer

ملف التثبيت اسمه WridDietPos-0.3.14-x64.msi (حوالي 51 ميجابايت). احصل عليه بإحدى الطريقتين:

The installer is WridDietPos-0.3.14-x64.msi (about 51 MB). Get it one of two ways:

  1. رابط مباشر (الأسهل): تنزيل WridDietPos-0.3.14-x64.msi
    https://github.com/3nady/wrid-diet-desktop-releases/releases/download/v0.3.14/WridDietPos-0.3.14-x64.msi
    الرابط عام ولا يحتاج تسجيل دخول. صفحة الإصدار: v0.3.14
  2. نسخ مباشر: انسخ الملف بذاكرة USB من الجهاز الذي بُني عليه، من المجلد D:\Wrid System\diet-pos\desktop\artifacts\.
  1. Direct link (easiest): Download WridDietPos-0.3.14-x64.msi
    https://github.com/3nady/wrid-diet-desktop-releases/releases/download/v0.3.14/WridDietPos-0.3.14-x64.msi
    The link is public, no sign-in needed. Release page: v0.3.14
  2. Direct copy: copy the file on a USB stick from the PC it was built on, folder D:\Wrid System\diet-pos\desktop\artifacts\.

3التثبيتInstall

  1. انقر نقراً مزدوجاً على WridDietPos-0.3.14-x64.msi.
  2. إذا ظهرت نافذة «حمى Windows جهاز الكمبيوتر» (SmartScreen): اضغط «مزيد من المعلومات» ثم «تشغيل على أي حال». تظهر لأن الملف غير موقّع رقمياً بعد.
  3. في نافذة الترحيب اضغط Next. اترك مجلد التثبيت كما هو (C:\Program Files\Wrid Diet) واضغط Next. في صفحة «خيارات التثبيت» اختر «إنشاء اختصار على سطح المكتب» (مفعّل افتراضياً) و«التشغيل تلقائياً مع بدء Windows» (غير مفعّل افتراضياً)، ثم Next وInstall.
  4. وافق على طلب صلاحية المسؤول (UAC) بالضغط على نعم.
  5. عند الانتهاء اضغط Finish؛ الخيار «تشغيل البرنامج الآن» يفتحه مباشرة. ستجد اختصار «وريد دايت - Wrid Diet» في قائمة ابدأ، وعلى سطح المكتب إذا اخترته.
  1. Double-click WridDietPos-0.3.14-x64.msi.
  2. If "Windows protected your PC" (SmartScreen) appears: click More info, then Run anyway. It shows because the file is not code-signed yet.
  3. On the welcome page click Next. Keep the install folder (C:\Program Files\Wrid Diet) and click Next. On the Install options page choose "Create a desktop shortcut" (on by default) and "Start with Windows" (off by default), then Next and Install.
  4. Accept the administrator prompt (UAC) with Yes.
  5. Click Finish; "Launch now" opens the app at once. A "وريد دايت - Wrid Diet" shortcut is in the Start menu, and on the desktop if you chose it.

تثبيت صامت (لعدة أجهزة)Silent install (many tills)

من نافذة «موجّه الأوامر» بصلاحية المسؤول، في مجلد الملف:

From an administrator Command Prompt, in the file's folder:

msiexec /i WridDietPos-0.3.14-x64.msi /qn

الخيارات في التثبيت الصامت: DESKTOP_SHORTCUT=0 بدون اختصار على سطح المكتب، وSTART_WITH_WINDOWS=1 للتشغيل مع بدء Windows. يُحفظ الاختيار للتحديثات القادمة.

Options for a silent install: DESKTOP_SHORTCUT=0 for no desktop shortcut, START_WITH_WINDOWS=1 to start with Windows. The choice is kept for later updates.

4أول تشغيلFirst run

  1. افتح «وريد دايت - Wrid Diet» من سطح المكتب. اللغة الافتراضية العربية، وزر English في شاشة الدخول يغيّرها.
  2. أدخل رقم الجوال بعد +966 بدون الصفر (مثال 5XXXXXXXX) وكلمة المرور، ثم اضغط تسجيل الدخول.
  3. من القائمة الجانبية افتح «كاشير الوجبات». إذا لم تكن هناك وردية مفتوحة: اختر نقطة البيع، أدخل الرصيد الابتدائي، واضغط فتح الوردية.
  4. من الصفحة الرئيسية افتح «بيع مباشر»: قائمة الطعام والمكونات والقوالب على جهة، والسلة على الجهة الأخرى.
  1. Open "وريد دايت - Wrid Diet" from the desktop. It starts in Arabic; the English button on the login screen switches it.
  2. Enter the mobile number after +966, without the leading zero (e.g. 5XXXXXXXX), and the password, then sign in.
  3. From the side menu open "كاشير الوجبات" (Meals cashier). With no open shift: pick the POS, enter the opening balance and press Open shift.
  4. From the home page open "بيع مباشر" (Direct sale): menu, components and molds on one side, cart on the other.

6طابعة الملصقاتLabel printer

  1. ثبّت تعريف طابعة الملصقات (مثل Zebra أو Xprinter) في Windows.
  2. في الإعدادات ← الطابعات اختر طابعة الملصقات، أو من شاشة البيع اضغط F8 واخترها من قائمة «طابعة الملصقات».
  3. في نافذة الملصقات راجع المعاينة: طريقة الطباعة، الهامش الجانبي، حجم النص، تدوير الطباعة، والحقول الظاهرة (السعرات، البروتين، تاريخ الانتهاء، مسببات الحساسية، رمز QR...).
  4. اضغط F6 أو زر الطباعة. اطبع ملصقاً تجريبياً أول مرة.
  1. Install the label printer's driver (e.g. Zebra or Xprinter) in Windows.
  2. In Settings → Printers choose the Label printer, or press F8 on the sale screen and pick it from "Label printer".
  3. In the labels dialog check the preview: Print method, Side margin, Text size, Rotation and Visible fields (calories, protein, expiry date, allergens, QR code…).
  4. Press F6 or the print button. Print a Test label the first time.

7عنوان الخادمServer address

يتصل البرنامج افتراضياً بالخادم https://api.dev.wrid.sa. لا تغيّره إلا بطلب من الدعم الفني. طريقتان للتغيير:

By default the app connects to https://api.dev.wrid.sa. Change it only when support asks you to. Two ways:

  • لهذا المستخدم: الإعدادات ← عنوان الخادم ← حفظ. يُسجَّل خروجك بعد التغيير.
  • لكل مستخدمي الجهاز: افتح المفكرة كمسؤول، وعدّل الملف C:\Program Files\Wrid Diet\appsettings.json. التحديثات اللاحقة تحافظ على هذا التعديل.
  • For this user: Settings → Server address → Save. You are signed out after the change.
  • For every user of the PC: open Notepad as administrator and edit C:\Program Files\Wrid Diet\appsettings.json. Later updates keep the edit.
{
  "ApiUrl": "https://api.dev.wrid.sa"
}
تنبيه
Caution
الخادم api.dev.wrid.sa يعمل على قاعدة البيانات الحقيقية. كل بيع أو اشتراك أو وردية تجريبية تُسجَّل فعلاً لدى الشركة. جرّب بحساب شركة تجريبية. api.dev.wrid.sa runs on the real database. Every test sale, subscription or shift is recorded for the company. Test with a test company account.

8التحديث والإزالةUpdate and remove

  • التحديث: شغّل ملف MSI للإصدار الأحدث بنفس الطريقة. يحلّ محل القديم مباشرة وتبقى الجلسة والإعدادات والطابعات كما هي. لا داعي لإزالة القديم أولاً. لا يمكن تثبيت إصدار أقدم فوق إصدار أحدث.
  • الإزالة: الإعدادات ← التطبيقات ← «وريد دايت - Wrid Diet» ← إلغاء التثبيت.
  • بيانات المستخدم (الجلسة، الإعدادات، الطابعات، البيانات المحفوظة، السجلات) في %LOCALAPPDATA%\WridDietPos، ولا تُحذف عند الإزالة. احذف المجلد يدوياً لإزالتها بالكامل.
  • Update: run the newer version's MSI the same way. It replaces the old one in place; the session, settings and printers are kept. No need to uninstall first. An older version can't be installed over a newer one.
  • Remove: Settings → Apps → "وريد دايت - Wrid Diet" → Uninstall.
  • User data (session, settings, printers, saved data, logs) is in %LOCALAPPDATA%\WridDietPos and is not deleted on uninstall. Delete that folder by hand to remove it completely.
